 <!-- What is the difference between var, let, and const? -->
ans -- var, let, and const differ primarily in scope, hoisting, and reassignability. var is function-scoped and hoisted, let and const are block-scoped. Use const for immutable variables, let for reassignable variables, and avoid var. 

<!-- What is the spread operator (...)? -->
ans -- The spread operator (...), introduced in ES6, is a JavaScript feature that expands iterables (like arrays, objects, or strings) into individual elements. It is used to quickly copy, merge, or pass data, making code more concise. Common use cases include shallow copying arrays, merging objects, and passing array elements as function arguments.

<!-- 3️⃣ What is the difference between map(), filter(), and forEach()? -->
ans -- The primary difference is their purpose and return value: forEach() is for performing an action (side effect) and returns nothing (undefined), while map() and filter() both return a new array based on their operations.
